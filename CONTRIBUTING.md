# Contribuir a ArbitraPDF

El proyecto aún se encuentra en una etapa temprana.

## Tipos de contribución

- reportar errores;
- proponer herramientas;
- describir flujos documentales reales;
- probar archivos problemáticos no sensibles;
- mejorar documentación;
- aportar código cuando se defina el modelo de colaboración.

## Reportes de errores

Un buen reporte debería incluir:

- versión de ArbitraPDF;
- versión de Windows;
- herramienta utilizada;
- formato de entrada;
- pasos para reproducir;
- mensaje de error;
- si es posible, un archivo de prueba sin información sensible.

No adjuntar expedientes reales o confidenciales en issues públicos.

## Funcionalidades

Las solicitudes deben explicar:

1. problema real;
2. flujo manual actual;
3. resultado esperado;
4. formatos involucrados;
5. volumen aproximado de documentos.

## Código

Las reglas de contribución de código se ampliarán cuando se defina la licencia del proyecto.
