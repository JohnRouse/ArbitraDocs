# Changelog

Todos los cambios relevantes del proyecto se documentarán aquí.

## [Unreleased]

### Cambio de identidad y alcance

- El proyecto pasa de **ArbitraPDF** a **ArbitraDocs**.
- ArbitraDocs se redefine como una **suite gratuita de herramientas documentales**.
- El alcance deja de centrarse exclusivamente en expedientes y se amplía a PDF, Office e imágenes.

### Decisiones mantenidas

- Procesamiento local por defecto.
- Aplicación Windows sin requerir Python al usuario final.
- Privacidad por diseño.
- Herramientas principales gratuitas.
- Donaciones voluntarias como mecanismo de apoyo potencial.
- Arquitectura modular y pruebas automatizadas.
