# Privacidad

## Principio

Los documentos del usuario pertenecen al usuario. ArbitraPDF está diseñado para procesarlos localmente en su computadora.

## Documentos

La arquitectura prevista no requiere:

- subir PDFs;
- subir ZIP/RAR;
- subir correos;
- enviar anexos;
- almacenar expedientes en servidores de ArbitraPDF.

## Datos de uso

En la primera versión pública no se prevé telemetría invasiva.

Si en el futuro se incorpora analítica opcional:

- deberá documentarse;
- no podrá incluir nombres de archivos ni contenido documental;
- deberá respetar el consentimiento del usuario.

## Temporales

Durante conversiones complejas pueden crearse copias temporales locales.

La aplicación debe:

- utilizar ubicaciones temporales controladas;
- eliminarlas cuando termine;
- conservarlas únicamente cuando sea necesario para recuperación explícita.

## Web

La página web podrá registrar los datos técnicos habituales del alojamiento web, pero la herramienta de escritorio no dependerá de la web para procesar documentos.

## Donaciones

Las donaciones se gestionarán mediante proveedores externos. ArbitraPDF no necesita acceder a los datos financieros del usuario.
