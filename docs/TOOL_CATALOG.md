## Estados

- **Núcleo iniciado:** ya existe implementación dentro de la nueva arquitectura.
- **Prototipo funcional / por integrar:** existió una herramienta/prototipo separado y debe migrarse a ArbitraDocs.
- **Prototipo previo / por integrar:** existe experiencia/código previo que debe adaptarse al nuevo núcleo.
- **Diseñada / por implementar:** comportamiento funcional documentado, implementación pendiente.
- **Planificada:** incluida en el producto, diseño técnico pendiente.
- **Investigación/planificada:** requiere validar bibliotecas y calidad antes de comprometer una implementación concreta.

## Regla de producto

Todas las herramientas principales de este catálogo se plantean como gratuitas para el usuario final. La gratuidad del producto y la licencia del código fuente son decisiones diferentes; la licencia se definirá por separado.
