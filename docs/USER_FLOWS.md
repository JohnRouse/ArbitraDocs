# Flujos principales de usuario

## Procesar un expediente ZIP

1. Abrir **Procesar expediente**.
2. Seleccionar ZIP.
3. ArbitraPDF inspecciona carpetas.
4. Ordena fechas de menor a mayor.
5. Muestra resumen.
6. Usuario configura A4, color, compresión y foliación.
7. Procesar.
8. Generar PDF + reporte.

## Foliar varios expedientes correlativamente

1. Abrir **Foliación correlativa**.
2. Agregar múltiples PDFs/expedientes.
3. Reordenar mediante drag & drop.
4. Indicar número inicial.
5. Elegir ascendente/descendente.
6. Elegir número/letras.
7. ArbitraPDF calcula rangos.
8. Confirmar.
9. Guardar archivos separados y/o unificados.

## Certificación al reverso

1. Seleccionar PDF principal.
2. Seleccionar certificación.
3. Elegir página de certificación si tiene varias.
4. Mostrar cálculo: N páginas principales + N certificaciones = 2N páginas finales.
5. Generar PDF.
6. Imprimir a doble cara.

## Escrito + Anexos simple

1. Seleccionar escrito.
2. Seleccionar ZIP/RAR.
3. ArbitraPDF extrae anexos.
4. Detecta carpetas/archivos.
5. Ordena Anexo 1, 2, 3…
6. Muestra vista previa.
7. Usuario corrige si desea.
8. Generar PDF final.

## Escrito + Anexos avanzado

1. Arrastrar múltiples elementos a una bandeja: Escrito 1, ZIP 1, Escrito 2, RAR 2 y otros documentos.
2. ArbitraPDF muestra cada elemento como tarjeta.
3. ZIP/RAR se pueden desplegar.
4. Usuario reordena bloques y elementos internos.
5. Archivos incompatibles aparecen señalados.
6. Procesar.
7. Resultado = un único PDF en el orden visual exacto.
8. Generar reporte final.
